Installer en 3 étapes

OwnMac n'est pas notariée par Apple. macOS bloquera donc le premier lancement : c'est attendu.

  1. Télécharge et décompresse le zip, puis glisse OwnMac dans ton dossier Applications.
  2. Ouvre l'app une première fois. macOS refuse et affiche un avertissement : ferme-le.
  3. Autorise-la dans Réglages Système > Confidentialité et sécurité, avec le bouton Ouvrir quand même.

Avec le Terminal, tu peux aussi lever le blocage : xattr -dr com.apple.quarantine /Applications/OwnMac.app. Au premier lancement, OwnMac s'ajoute à tes éléments de connexion ; une bascule dans Réglages permet de l'enlever.

Clair sur ce qu'elle fait

Confidentialité

  • Aucun compte, aucune télémétrie, aucune donnée envoyée.
  • Seule connexion possible : la vérification des mises à jour sur GitHub. Elle est désactivée tant que tu ne l'acceptes pas.
  • Le presse-papier reste en mémoire et disparaît quand tu quittes l'app.
  • Les images de la webcam sont analysées puis jetées.
  • Le code est open source (licence MIT), tu peux tout vérifier.

Limites

  • La musique ne marche qu'avec Musique et Spotify, pas dans un navigateur.
  • La webcam détecte un visage, pas le tien : elle ne déverrouille rien.
  • La chaleur s'affiche en niveaux, pas en degrés.
  • Les mises à jour se téléchargent à la main : l'app te prévient, sans s'installer seule.
  • Le verrouillage repose sur une API privée qu'une mise à jour de macOS pourrait casser.
